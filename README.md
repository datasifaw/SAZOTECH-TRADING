# SAZOTECH-TRADING

A lightweight Trading Order Management System built with C# and ASP.NET Core Web API.

## Overview

SAZOTECH-TRADING is an educational project that simulates the management of stock market trading orders.

## Tech Stack

- C# / .NET 10
- ASP.NET Core Web API
- SQL Server
- Entity Framework Core
- Swagger / OpenAPI
- Docker
- Git and GitHub
- xUnit

## Planned Features

- Financial instrument management
- Buy and sell orders
- Simulated order execution
- Portfolio position tracking
- Trading history
- Business rule validation
- Unit testing

## Project Structure

- `SAZOTECH.Trading.API` — REST API project

## Getting Started

```bash
dotnet restore
dotnet build
dotnet run --project SAZOTECH.Trading.API
```

## Project Status

Phase 0 — Initial setup.

## Disclaimer

This is an educational application. All trading operations are simulated. No real financial transactions are performed.
